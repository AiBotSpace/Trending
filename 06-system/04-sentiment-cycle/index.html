游资情绪周期研究覆盖层¶

这是 TS-A-SENTIMENT-V0 研究覆盖层，不是 RC1 的新市场闸门。它借用游资常用的“冰点—修复—发酵—高潮—分歧—退潮”语言，把短周期风险偏好转成可记录的收盘指标。它只能降低新增风险，不能把 Red/Yellow 提升为 Green，也不能放宽组合硬上限。

先说边界¶

“情绪周期”是交易圈的经验框架，没有统一的官方定义。本文把它当作一个待验证的状态分类器，而不是预测市场的因果模型。所有指标必须在正式收盘后冻结，供下一交易日使用；不使用盘中未来信息，也不把“龙头”当成无需记录的主观标签。

当前 V0 范围固定为沪深主板、非 ST、适用 10% 涨跌幅的普通股，与 RC1 股票池边界一致。创业板、科创板、北交所和 B 股的涨跌停制度、连板结构和成交行为不同，必须另建适配器。

六个阶段¶

阶段 可观测特征 新增风险倍率上限 操作含义
冰点 ice 涨停/跌停比极低、晋级弱、炸板高、涨停溢价和龙头收益转负 0 停止新增风险；等待修复证据
修复 repair 低位指标连续改善，亏损反馈收敛，但持续性尚未确认 0.5 只做最高质量候选的影子预检，不主动加仓
发酵 expansion 涨停宽度、晋级率、溢价和龙头反馈同步改善 1.0 仍需通过 MarketMode、Candidate/Setup 和流动性闸门
高潮 climax 高度、晋级率和溢价都极强，拥挤与追价风险上升 0.5 不把强势当成满仓理由，禁止仅凭情绪加仓
分歧 divergence 前一阶段很热但评分快速回落或炸板率跳升 0.5 降低新增风险，暂停情绪驱动的加仓
退潮 recession 得分持续偏弱但尚未达到极端冰点 0 停止新仓，优先处理已有风险

若证据无法进入上述阶段，输出 mixed，倍率上限为 0.5；数据缺失则不是 mixed，而是 DATA_BLOCKED。

程序在没有前一日快照时，即使当日五项指标都很强，也只输出 mixed 和 phase_provisional=true；只有递增日期的历史 CSV 或合法的前一日快照，才允许确认修复、发酵、高潮或分歧等转折阶段。

这套理论在观察什么¶

游资情绪周期不是“预测指数涨跌”的模型，它观察的是短线资金对高波动机会的承接能力。一个涨停板本身只说明某个价格结果，周期要回答的是四个更具体的问题：

  1. 参与面：有多少股票同时获得资金关注，赚钱效应是否从单点扩散到板块和市场；
  2. 接力面：前一天强势股票，第二天是否还有资金愿意以更高价格承接；
  3. 兑现面：强势股票兑现时，回撤是否温和，还是快速从涨停变成跌停；
  4. 持续面：高标、板块和龙头反馈是否能维持几个交易日，而不是只出现一次脉冲。

因此，周期的核心不是“数板”，而是观察“正反馈是否扩散、是否持续、是否开始反噬”。它与趋势系统的关系也不同：趋势模板观察中期供需结构，情绪周期观察数日级别的资金承接；短周期很热不能证明中期趋势成立，短周期很冷也不能自动否定中期结构。

周期不是单向钟表¶

经典叙述常写成：

冰点 → 修复 → 发酵 → 高潮 → 分歧 → 退潮
  ↑                                      ↓
  └────────────── 再次寻找新平衡 ────────┘

实际市场可能跳过阶段、在修复和分歧之间反复，或者因为政策、指数跳空、监管和流动性事件直接从发酵进入退潮。因此，程序使用“当前分数 + 前一阶段 + 分数变化”做有限状态判断，而不是强行让每天沿着六个节点顺序移动。

关键转折¶

转折 需要看到的证据 不能据此推出的结论
冰点 → 修复 负反馈收敛，涨停/跌停比、晋级率或溢价至少有一项明显改善，且不是单只股票独撑 不是确认牛市，也不是立即满仓
修复 → 发酵 改善从单只龙头扩散到多个行业/梯队，晋级与龙头收益同步 不是所有涨停都具备趋势质量
发酵 → 高潮 高度、晋级和溢价极强，参与者拥挤，追价增多 强度越高不代表未来收益越高
高潮 → 分歧 分数下降至少两个单位、炸板率跳升或龙头反馈恶化 一天分歧不等于立即清空所有中期仓位
分歧 → 退潮 负反馈扩散，跌停和失败接力增加，修复尝试失败 不能用下一只强势股掩盖组合风险
退潮 → 冰点 负反馈达到极端，市场短线参与意愿显著收缩 冰点不等于马上反转，仍需等待修复

状态转换必须保存前一日快照。没有前一日证据时，程序宁可给 mixed，也不把一组强指标包装成“新周期确认”。

六个阶段的详细读法¶

冰点：先保护选择权¶

冰点的典型表现是涨停家数少、跌停家数多、晋级率低、炸板率高，昨日涨停组第二天整体亏损，龙头篮子也无法提供正反馈。此时最重要的不是寻找“最低点”，而是避免在负反馈扩散时继续消耗风险预算。

可做的事：

  • 保存失败样本，区分市场性失败、板块性失败和个股事件；
  • 更新候选池，但只做观察和影子预检；
  • 检查已有头寸的 CommittedHeat、可卖数量、财报和停牌风险；
  • 等待至少一个可复核的修复信号。

不应做的事：

  • 因为“跌得多”而降低趋势和事件标准；
  • 把一只逆势涨停股称为新周期龙头；
  • 用摊平亏损的方式博取情绪反转。

修复：只验证，不追求效率¶

修复阶段通常先出现局部改善：跌停减少、昨日涨停溢价回到零附近、少数板块出现连续性，随后才可能出现晋级率提升。修复的难点是把真实改善与消息刺激、个股独立事件区分开。

仓位上限设为半风险，且不主动开启第 2/3 段加仓。若修复信号只来自一个主题，breadth_ratio 和行业扩散仍应记为中性，不能提前升级为发酵。

发酵：正反馈开始扩散¶

发酵不是“涨停越多越好”，而是多个指标同时改善：参与面扩大，前一日强势股有承接，板块内部出现梯队，龙头收益不再依赖单一股票。发酵阶段才有资格讨论渐进建仓，但仍必须先通过 RC1 的 MarketMode、CandidateGrade、SetupGrade、事件和流动性检查。

发酵中的常见误判是把盘中快速拉升当成收盘确认。V0 只接受正式收盘后的快照，下一交易日执行也不能把收盘结果当成已成交事实。

高潮：强度和拥挤同时出现¶

高潮阶段的指标往往最漂亮：连板高度高、晋级率高、涨停溢价高，社交媒体和盘面关注度也高。但这些指标同时意味着潜在兑现集中，后续收益分布可能变宽，追价和隔夜缺口风险上升。

因此 V0 把高潮风险倍率限制为 0.5，并禁止情绪覆盖层直接允许加仓。已经通过中期趋势和交易许可的仓位仍按退出规则管理；情绪周期不能单独触发卖出，但可以触发“暂停新增、取消未成交加仓计划、重新核对热度”的操作。

分歧：判断是换挡还是退潮¶

分歧不是简单的“涨停少了一点”。需要观察负反馈是否集中在低质量题材，还是已经传导到前期核心龙头；还要看昨日涨停溢价是小幅下降，还是转为系统性负值。

分歧阶段最有价值的记录是：

  • 哪些龙头仍守住关键结构；
  • 哪些板块先出现炸板和亏钱效应；
  • 失败是否集中在追价、低流动性或事件缺失的交易；
  • 五维 MarketMode 是否同步降级。

分歧可以回到修复，也可以进入退潮。没有连续证据时，采用更低的风险权限，不做“最后一次冲高”的主观假设。

退潮：从赚钱效应转向风险扩散¶

退潮阶段的核心不是指数一定下跌，而是高波动机会的盈亏比恶化：接力失败增多，昨日强势股无法获得溢价，龙头篮子和板块宽度同时转弱。此时停止新仓，优先处理已有头寸的退出、热度和事件风险。

退潮与冰点的区别是程度和结构：退潮可能仍有局部涨停，冰点则是负反馈达到极端。两者都不允许通过“还有一只强票”恢复新增风险权限。

分数如何落到阶段¶

五个方向指标分别记 +1 / 0 / -1，总分范围为 -5..+5。初始 V0 阈值如下：

指标 +1 0 -1
涨停/跌停比 ≥3.0 1.0–3.0 ≤1.0
晋级率 ≥30% 15%–30% ≤15%
炸板率 ≤20% 20%–40% ≥40%
昨日涨停溢价 ≥1% -1%–1% ≤-1%
龙头中位收益 ≥2% -2%–2% ≤-2%

总分只描述当日强弱，阶段还会读取前一阶段和分数变化：

  • score <= -3 且跌停不少于涨停：ice；
  • score <= -2：recession；
  • 前一阶段为 expansion/climax 且分数下降至少 2，或炸板率达到 40%：divergence；
  • 前一阶段为 ice/recession/divergence 且分数至少改善 1：repair；
  • 分数至少 4、最高高度至少 5 板、晋级率至少 40%：climax；
  • 其余分数至少 2：expansion；
  • 其他：mixed。

这个顺序是一个可测试的起点，不是自然规律。尤其是 climax 和 divergence 需要连续快照；只给一日数据无法确认“由热转冷”。

指标口径¶

V0 使用五个方向性指标和一个高潮确认条件：

  1. 涨停/跌停比：当日有效涨停家数 ÷ max(有效跌停家数, 1)；涨跌停价格必须来自证券—日期适配器，不能把日线涨跌幅近似为封板。
  2. 晋级率：前一交易日首次涨停且满足样本条件的股票中，下一交易日收盘再次涨停的比例。分母、剔除停牌和一字板的规则必须随快照保存。
  3. 炸板率：盘中触及适用涨停价但收盘未封住的比例。没有可靠的盘中触板/封单数据时不得填 0。
  4. 昨日涨停溢价：昨日有效涨停组在今日正式收盘相对昨日收盘的中位收益。它是群体反馈，不是单只龙头收益。
  5. 龙头中位收益：预先冻结的领涨样本篮子今日正式收盘中位收益；样本来源、筛选日和 evidence_id 必须可追溯。
  6. 高度/空间：最高连续涨停板数，只用于识别高潮拥挤，不单独产生买入信号。

V0 的初始阈值是研究起点，至少经过分层回放、样本外检验和不同市场制度校验后才可调整；调整必须版本化，不得覆盖已验证的基线。

与 MarketMode 的组合关系¶

MarketMode 是中慢周期硬闸门，情绪阶段是短周期覆盖层。最终权限始终取更严格值：

MarketMode 情绪阶段 总暴露硬上限 情绪覆盖层动作 最终含义
Green expansion 80% 风险倍率上限 1.0 可按许可矩阵渐进建仓，不把 80%当目标
Green climax/divergence/repair/mixed 80% 风险倍率上限 0.5 降低新增风险，高潮和分歧不主动加仓
Green recession/ice 80% 风险倍率 0 停止新增；已有仓位仍按独立退出规则管理
Yellow expansion 30% 不放大 Yellow 权限 仍只有 A/A 可用 half_r
Yellow 其他非阻断阶段 30% 取 Yellow 与情绪倍率的更小值 不能因情绪热而升级为 Green
Red 任意阶段 0% 情绪信号无权恢复风险 取消新仓和加仓，按规则降风险

情绪覆盖层影响的是新增风险倍率，不是自动目标仓位，也不是单独的退出信号。例如 Green + 冰点时，总暴露硬上限仍记录为 80%，但新增风险权限为 0；这意味着停止新增，不意味着忽略个股退出规则把所有仓位机械清零。

每日工作流¶

收盘后¶

  1. 冻结证券—日期适配器和原始行情版本；
  2. 计算有效涨停、跌停、触板和连板样本；
  3. 复算昨日涨停组和冻结龙头篮子的收盘反馈；
  4. 填写 sentiment-cycle.csv，生成带 evidence_id 的快照；
  5. 与前一交易日快照比较，生成阶段和风险倍率；
  6. 将结果传给仓位建议器，保存最终原因码；
  7. 人工复核是否存在政策、停牌、数据源或市场制度异常。

下一交易日盘前¶

  • 核对情绪快照日期是否与 MarketSnapshot 一致；
  • 若 MarketMode、回撤、LossStreakR、CommittedHeat 或情绪覆盖层任一为 0 权限，取消新增计划；
  • 对允许继续的计划重新计算首仓数量、执行窗口参与率和风险预留；
  • 不因隔夜新闻临时改写昨日正式收盘的阶段。

盘中和收盘¶

盘中只执行已经通过的计划。情绪阶段不是临场追涨按钮；若盘中出现快速分歧，只能触发预定义的取消、暂停或风险复核动作。收盘后再形成下一交易日使用的新快照。

运行与应用¶

情绪快照用一张按日期递增的表格（CSV 或电子表格）逐日维护，字段与填写规则见上一节“每个字段要保存什么”。手工流程如下：

  1. 追加当日一行，填入七个原始指标及其证据来源；
  2. 与上一交易日快照对比，按 V0 阈值表判定当前阶段（高潮 / 分歧 / 修复 / 冰点 / 退潮 / 发酵）；
  3. 由阶段查得风险倍率，并保存判定理由与 evidence_id；
  4. 把倍率作为可选覆盖层输入仓位决策：最终新增风险上限取 min(MarketMode 许可, 回撤许可, 连续亏损许可, 组合热度许可, 情绪阶段倍率)；
  5. 归档当日快照，保留历史序列以便后续分层回放。

若只有单日数据，只能得到单日初判，不能形成阶段序列；若日期重复、倒序或出现未来日期，必须拒绝该快照，防止阶段标签产生未来信息泄漏。

情绪覆盖层的边界：

  • 高潮不会提高仓位，只会把新增风险降档；
  • 冰点和退潮不会自动抄底；
  • 情绪覆盖层缺失时不改变 RC1 结果；快照过期或日期不一致时阻断新增；
  • 情绪指标不能替代 CandidateGrade、SetupGrade、财报/解禁/监管事件检查、ADV20、执行窗口或风险预留。

验证方法¶

不要只看几次“冰点后反弹”。回放至少按 MarketMode × 情绪阶段 × CandidateGrade/SetupGrade 分层，记录：

  • 次日开盘和执行窗口的滑点、首仓失败率；
  • 5 日守住枢轴比例、10 日达到 +1R 比例；
  • 高潮降档是否减少追价损失；
  • 冰点/退潮停止新仓是否减少组合热度和回撤；
  • 指标缺失、制度变化和样本选择对结果的影响。

常见误区与反例¶

把涨停家数当成赚钱效应¶

涨停数量可能因为市场整体波动、板块制度或低价股集中而增加。如果涨停同时伴随晋级率下降、炸板率上升和昨日涨停组负溢价，数量增加并不代表接力质量改善。至少要同时观察参与面、接力面和兑现面。

把最高板当成唯一龙头¶

最高连板股票可能是小样本、事件驱动或即将兑现的极端值。龙头篮子必须在信号出现前冻结，不能每天收盘后选出表现最好的股票再计算“龙头收益”，否则会产生严重的幸存者偏差和未来信息泄漏。

把高潮当成趋势确认¶

高潮只说明短线资金在某个时间点高度集中；它不能证明个股满足 MA50/150/200、基本面、事件和可执行止损条件。趋势系统仍以中期结构和 MarketMode 为主，情绪层最多把新风险降档。

把冰点当成抄底信号¶

冰点阶段的反弹概率和反弹时点都不稳定，且 T+1、涨跌停和流动性枯竭会让“看对方向”不等于“能按计划退出”。V0 的冰点倍率为 0，先等待修复证据，正是为了避免把情绪极端误读为入场触发。

忽略制度和板块差异¶

10%板、20%板、ST、次新股和不同交易所的涨跌停、上市历史和可成交性不同。混合统计会把制度差异误当成情绪变化。若扩展范围，必须重新定义有效涨停、连板、炸板、样本分母和阈值，并单独回测。

用日线高低价推断炸板¶

日线最高价接近涨停价不代表盘中曾经封板；没有逐笔或分钟数据，就不能可靠区分触板、封板、开板和未触板。无法取得盘中证据时，程序应返回数据阻断，而不是把炸板率填为 0。

回测和研究设计¶

情绪周期最容易在回测中被“看起来有效”，研究时要提前冻结以下内容：

  1. 决策时点：所有输入只用当日正式收盘前可得数据，下一交易日执行价格单独建模；
  2. 样本范围：固定主板、非 ST、10%板范围，记录停牌、退市、涨跌停和上市不足样本；
  3. 指标版本：保存阈值配置哈希、数据源版本、证券日期适配器版本和 evidence_id；
  4. 阶段标签：阶段由当日及前一日快照机械生成，不能由后续收益反推；
  5. 结果分层：至少按 MarketMode、情绪阶段、CandidateGrade、SetupGrade、行业和流动性分层；
  6. 成本与成交：记录涨停无法成交、T+1、滑点、撤单、部分成交和隔夜跳空，不能只用收盘价成交；
  7. 缺失数据：缺数据样本单列为 DATA_BLOCKED，不能从胜率统计中悄悄删除；
  8. 样本外验证：阈值调整必须在新时间段和不同制度样本上验证，并与不使用情绪覆盖层的基准组合比较。

建议的最小报告包括：阶段转移频率、每个阶段的次日/5日/10日收益分布、首仓失败率、滑点、最大回撤、组合热度和“情绪降档前后”的差异。单看平均收益不足以证明情绪周期有效。

记录字段与审计问题¶

每个情绪快照至少回答以下问题：

  • 哪个交易日、哪个市场范围、哪个涨跌停制度？
  • 涨停/跌停的分子分母是什么，剔除了哪些股票？
  • 晋级率和炸板率的样本是否在当时已经确定？
  • 龙头篮子何时冻结，是否包含后来才被选出的赢家？
  • 本日阶段相对前一日为何变化，分数变化是多少？
  • 情绪倍率是否与 MarketMode、回撤、Heat 和 LossStreakR 取了更严格值？
  • 任何数据缺失是否被记录为阻断，而不是被填成中性？

若这些问题无法由快照、配置和原始证据回答，情绪周期只是一段复盘叙事，不应进入仓位建议。

若情绪覆盖层与五维市场闸门冲突，以更严格的风险权限为准，并保留两套证据。情绪周期不是让系统更快交易的理由，而是把“市场很热/很冷”的口语判断变成可复核的降档信号。
